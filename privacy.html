Privacy Policy

Last updated: September 26, 2026

RM7 Studio ("the app") is a desktop application used privately by the owner of the RM7 Setups YouTube channel to prepare and upload that channel's own videos. This policy explains what data the app accesses and what it does with it.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service, and the Google Privacy Policy applies to the data Google processes.

What data the app accesses

After the channel owner signs in with Google and grants permission, the app uses the YouTube Data API to:

  • read the name of the connected channel, to show which account is connected;
  • read the channel's playlists, to add new videos to the right playlist;
  • upload videos, thumbnails, titles, descriptions and tags that the owner prepared on their own computer;
  • create playlists and add videos to them.

The app does not read comments, viewers' information, analytics, subscribers or any other personal data of other people.

How the data is stored

  • All data stays on the owner's own computer. The app has no server and no online database.
  • The Google sign-in token is stored in a local file on that computer, and it is used only to talk to the YouTube Data API.
  • The app keeps a local record of each upload (video ID, title and date) so the owner can see what was uploaded.
  • The name of the connected channel is stored locally to show which account is connected, and it is deleted when the account is disconnected.
  • The list of playlists read from the API is only kept in memory for a few minutes to avoid repeated requests, and is never written to disk.

Sharing

The app does not share, sell or transfer any data to third parties. Data is only sent to Google/YouTube to perform the uploads the owner asked for. The app does not use cookies, advertising or tracking of any kind.

Deleting data and revoking access

  • The "Disconnect" button in the app deletes the stored Google token immediately.
  • Access can be revoked at any time from the Google security settings page: security.google.com/settings/security/permissions.
  • Deleting the app's data folder removes all locally stored data. To request deletion of any data, contact the address below; it will be deleted within 7 days.

Changes
